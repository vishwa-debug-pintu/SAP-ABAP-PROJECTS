# SAP ABAP Purchase Order Tracking System

## Project Description
Purchase Order Tracking System is one of my beginner SAP ABAP projects I have made using SAP ECC 6.0 to develop the program that will display the list of purchase order header and item information.

### Learning Objectives
1. Retrieve purchase order information using a purchase order number
2. Display the supplier number and purchase order date
3. Display material numbers, item numbers, and quantities ordered
4. Display unit of measures, plant, and net prices
5. Learn how to use open SQL joins and report programming

### SAP Tables
The following SAP tables I have used to develop the program:

| Table Name | Description |
| --- | --- |

| EKKO | Purchase order header data table |

| EKPO | Purchase order item data table |

### ABAP Concepts
The following concepts were demonstrated using the SAP ABAP Program below:
1. REPORT statement
2. PARAMETERS
3. TYPES and DATA declaration
4. SELECT statement
5. INNER JOIN
6. WHERE condition
7. Internal tables and work area
8. LOOP AT
9. WRITE statements
10. SY-SUBRC
### Tools Used
1. SAP ECC 6.0
2. SAP GUI
3. SE38 ABAP Editor
4. Visual Studio Code SAP ABAP
5. Git and GitHub
### Program Name
`Z_PO_TRACKING`
## Project Details
### Working Procedure
1. The user will enter the purchase order number
2. The program will display a list of purchase order details including the header and item information
3. The report will be displayed in an ABAP basic list output
4. A message will be displayed if a purchase order number does not exist
### Enhancements / Future Work
1. Show supplier names through LFA1 table
2. Track goods receipts using purchase order history
3. Use date, supplier, and plant filters
4. Display results using an ALV report output
### Conclusion
This project was a great opportunity for me to learn SAP ABAP. It is indeed a master key to SAP career.
