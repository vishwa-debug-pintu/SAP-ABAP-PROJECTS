# SAP ABAP Purchase Order Tracking System

## Project Description

The Purchase Order Tracking system is the beginner-level SAP ABAP project that uses the SAP ECC 6.0 to retrieve and display the purchase order (header and item) information.

## Learning Objectives

1. Get the Purchase Order (PO) information based on the input purchase order number.
2. Display the information of supplier number and date of purchase order.
3. Display the relevant information on material numbers, item numbers and quantity ordered.
4. Display the unit of measure, plant and net prices.
5. Learn to do the Open SQL joins and ABAP report programming.

## SAP Tables

S.No Table Description
1. EKKO Purchase Order Header Table
2. EKPO Purchase Order Item Table

## Program Name

`Z_PO_TRACKING`

## Working Procedure

1. The user will input the relevant purchase order number.
2. The program will get the relevant purchase order header and item details in SAP.
3. The output will be displayed in the basic ABAP list report.
4. There will be a message displayed if the input purchase order number is not found.
